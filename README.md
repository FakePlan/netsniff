# Mini Wireshark (Netsniff) 

A lightweight network packet capture and analysis tool built with C++. This project intercepts live network traffic, parses the essential data, and logs the information into a local SQLite database for further analysis.

## Features
- **Live Packet Sniffing:** Captures network traffic in real-time.
- **Packet Parsing:** Analyzes and extracts critical network data.
- **Database Integration:** Securely logs captured packet details into an SQLite database (`packets.db`).

## Technologies Used
- **C++**
- **SQLite3**
- Visual Studio (MSVC)
